# Synthetic impact model

PHL = Σticks Σagents exposure × (1-effectiveService) × 1/6, measured in synthetic person-hours of essential-service loss. It is neither casualty prediction nor lives saved. Service exposures overlap, so the sum is not a unique population.

| Agent | Synthetic exposure |
|---|---:|
| Hospital | 3,000 |
| Emergency | 10,000 |
| Water | 150,000 |
| Telecom | 150,000 |
| Shelter | 12,000 |
| Traffic | 30,000 |
| Fuel | 10,000 |
| Residential | 150,000 |
| Commercial | 20,000 |
| Transit | 25,000 |

Every strategy uses identical profiles, environment schedule and demand seed. Failures of software agents hold their physical draw; disabling participation instead creates an uncontrolled priority draw. These are modelling assumptions, not empirical behavioral estimates. Quantiles describe simulated futures or seeds only. Baseline comparisons do not imply council dominance on every objective.
