# Local demonstration runbook

1. Run `npm run dev` (or production `npm run preview`). Use `?seed=42` for a reproducible live scenario. The council prepares six 30-minute blocks, validates them, and runs 30 seeded futures before requesting approval. Read the document/hash and guardrails, approve, then Run. Auto mode still stops when a guardrail fails.
2. At tick 12 (02:00), supply falls from 200 to 70 PU. Inspect the ten agents and actual BID → COUNTER/CONCEDE → ACCEPT → PREPARE → COMMIT messages. The Constitution checks proposals; the utilities compute them. Service can remain high while backup drains.
3. At tick 54 (09:00), supply is 55 PU and Central capacity 30 PU. Inspect the feeder table and triage. Green/amber/red/grey facility rings, flow particles and dependency ripples all use the current tick. Navigation, minimap, selection and the authored coastline remain available.
4. Choose static, equal or optimum comparison. Two viewports share authored geometry and a camera; separate workers produce the allocations. Same seed and clock, with intervention replay. View the metric comparison below the selector. Do not promise council wins; the recorded matrix says otherwise on some metrics.
5. Pause and open Inject a disruption → Drop bids. This forks from the displayed tick. Request/approve a new plan, Step, and inspect two ABORTs, fallback, the applied vector hash and zero applied violations. Toggle Residential off to see uncontrolled draw take priority; this assumption is explicitly labelled.
6. Open Plan & approval, reject with a note, and inspect the new proposal ID. Approve only the reviewed proposal. When a window completes, Verification shows actual versus p10–p90 and min–max. PASS is not staged; this seed can produce FAIL and escalation.
7. Scrub to a recorded tick and step through the same history. Change a toggle there to fork; earlier branches remain intact in worker/store memory. There is no durable persistence after reload.
8. Show `experiments/results/summary.md`: one cyclone × four strategies × 50 seeds = 200 actual runs. A separate 200-seed robustness test runs every strategy (800 runs / 115,200 applied ticks). Exposures are synthetic and overlapping; no lives-saved claim.

Before presenting: `npm run typecheck && npm run check:boundaries && npm test && npm run build`. Run the preview browser smoke test. `npm run demo` prepares the static offline folder. Use a local HTTP server with internet disconnected. A recorded fallback video has not been created by this implementation; do not describe it as available.
